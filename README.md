# ScreenOCR

Captura una zona de la pantalla o toma una foto con la cámara, y extrae el texto en **inglés y español**. Gratis y de código abierto.

## Enlaces

- **Sitio y app en línea:** https://humanx123.github.io/ScreenOCR/
- **Descargar para Android (APK):** https://github.com/humanx123/ScreenOCR/releases/download/v1.0.0/ScreenOCR-1.0.0.apk
- **Releases:** https://github.com/humanx123/ScreenOCR/releases

## Qué hay en este repositorio

| Carpeta | Contenido |
|---|---|
| `windows/` | App de escritorio para Windows (Python + PySide6). Captura con atajo global, OCR local con el motor de Windows o con OCR.space, instalador Inno Setup. |
| `android/` | App móvil (web + Capacitor). Cámara o galería, recorte, OCR con OCR.space y trabajos guardados en el dispositivo. |
| `web/` | Sitio de GitHub Pages con la descarga, la app en línea y los enlaces de apoyo. |

Consulta el README de cada carpeta para compilar y probar.
